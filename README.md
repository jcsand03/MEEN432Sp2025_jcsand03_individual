Instructions: To run this week's individual submission, download the p4_individual_init_cons.m, raceStat.m, p4_individual_portion.m, p4_individual_simulink.slx. First, run the p4_individual_init_cons.m to get all necessary car, battery, and motor data, as well as initial conditions. The initial conditions used were the ones provided in the project 4 folder by the professor. Next, run the p4_individual_portion.m script to get a plot of the car driving around the track with the added elevation changes, a plot of the energy consumed vs time, and the race stats. To get the race stats to appear, the raceStat file does not need to be run, just downloaded.

Background and Changes: For the individual portion the first changes I made were to the p4_individual_portion.m. This is the same script used for the project 4 team submissions, but I made my own changes to it. First, I added the straightaway z values using constant positive slope of tan inv of (10/900) for the first straightaway to increase the elevation from 0 to 10 meters. On the second straightaway the z values were added to the constant negative slope of tan inv of (10/900). Next, the two curves were assigned z coordinate values of 10 meters for the right curve and 0 meters for the left curve. Next, a 3D plot was created of the track using the plot3 command. This all generates a 3D interactive plot of the racetrack that the user can move and rotate. Once the track z coordinate was added, the car patch was assigned z dimensions. With the car and track initialized additions were made to the simulink model. The simulink model p4_individual_simulink.slx is the same base simulink model used in the team project submission for project 4, but additions were made. First off, the driver model was cleaned as unnecessary values were in the model as constant blocks that were not being used. Next, a subsystem named Z calculator was added to the driver model. This model takes in the X and Y position as inputs then passes them through a matlab function block that calculates the Z elevation at that X and Y value and the arc length. This subsystem outputs the Z value to the workspace and the other output is the slope at the current position that is passed out of the Z calculator and Driver subsystems. This slope is fed into the Dynamics subsystem. In this subsystem a matlab function block is added that calculates the gravitational forces as the car moves on the slopes. First, this function takes in the inputs of the car mass and the slope calculated in the Z calculator subsystem. Next, the matlab function returns the gravitational force by multiplying the mass of the car by the gravitational constant 9.81 then multiplied again by the sin of the slope. The  gravitational force is outputted and then inputted into the lateral dynamics matlab function. This force of gravity is then used to calculate the x velocity in the following equation: vx_dot = (Fw-Fb-Fdrag-Fg)/(M_in+carData.m) + vy*omega. Finally, the gain value in the throttle control portion of the driver model was recalibrated to be 0.009 through trial and error. 

Results: I was able to get the car to move at a desired velocity of 17.75 mph that completes 12 laps over the 1 hour period without leaving the track. The first lap takes 383 seconds to complete while the remaining laps take 276-276.5 second each time. Due to the car slowing down when going up the slope the car takes longer to complete the laps. Additionally, I noticed that in the plot of energy vs time that less energy was used when the car goes downhill as some braking is used to maintain the desired speed.
